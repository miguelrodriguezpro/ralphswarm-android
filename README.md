# RalphSwarm para Android

Descarga directa de la app de [RalphSwarm](https://ralphswarm.com) (sin Play Store).

**Descargar:** [ralphswarm.apk (última versión)](https://github.com/miguelrodriguezpro/ralphswarm-android/releases/latest/download/ralphswarm.apk)

## Instalar

1. Abre el enlace en el móvil Android y descarga `ralphswarm.apk`.
2. Ábrelo. Android pedirá permitir instalar apps de esta fuente («orígenes desconocidos»): acéptalo e instala.
3. Entra con tu usuario y contraseña de RalphSwarm.

## Actualizaciones

- Los cambios normales llegan solos: la app los descarga al abrirse y muestra **Reiniciar**.
- Cuando hay una versión nueva del APK, la app muestra **Instalar** y descarga la nueva versión; Android pide confirmar la instalación.

Este repositorio solo contiene las versiones publicadas (Releases), no el código.
